## Design notes for the reviewer

`scripts/shipped-files.js` is now the one place that defines the shipped
set (manifest-referenced paths plus `manifest.json`, `background.js`,
`dashboard/`, `src/`, `content/`). `test/helpers/no-network-scan.js`
imports it instead of keeping its own list. Widening the no-network scan
to cover `content/` is a real safety-guard change: it was not scanned
before this branch even though `content/bridge.js` and `content/page.js`
both ship. Covered by a new case in `test/no-network.test.js`, proven to
fail against the old scan before the fix (see progress log step 2).

No zip. The issue's acceptance boxes are met by the `dist/` folder alone;
a hand-rolled zip writer would have added binary-format code the tests
could not meaningfully exercise for no acceptance benefit. Chrome also
accepts a zip via drag-and-drop for anyone who wants to make one manually.

## Residual risk

None identified for this change. The build always deletes and rebuilds
`dist/` from scratch, so it cannot accumulate stale files across runs.
