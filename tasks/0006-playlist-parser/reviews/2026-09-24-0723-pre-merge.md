## Residual notes for the reviewer

- `droppedItems` counts a renderer only when the walk reaches it
  through an item array (`contents` or `continuationItems`), which is
  the only way YouTube serves items in this response family; a
  renderer appearing outside those arrays is picked up by upstream's
  fallback visit path and, in `parsePage`, would then also go through
  `consumeItemArray`-equivalent handling. The behaviour is covered by
  the garbage-input and the drop tests.
- The module is not added to `manifest.json`: it has no page-world or
  content-world role. `scripts/shipped-files.js` ships the whole `src/`
  directory, so it reaches `dist/` whenever the dashboard chain starts
  loading it.
