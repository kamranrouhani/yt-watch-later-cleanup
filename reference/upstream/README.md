This file is not loaded by the extension. It is the source the InnerTube
client, the playlist parser, the sort handling and the removal call were
ported from, kept so every port can be diffed against what it came from.

Upstream has no `LICENSE` file. Its README states MIT and the script header
carries `@license MIT`. The upstream notice in this repository's `LICENSE` is
therefore reconstructed: the standard MIT text, the author's GitHub handle as
the holder, and 2026 as the year of every upstream commit. If upstream ever
adds its own `LICENSE`, replace the reconstructed notice with it verbatim.

Do not edit this file. To take a newer upstream version, replace it whole and
update the table.
